# 마음, 한 잔

> 세 번의 선택으로 조심스럽게 마음을 전하고, 나에게 도착한 마음을 확인하는 솔로 파티용 웹 애플리케이션

![마음, 한 잔 대표 이미지](public/og.png)

## 프로젝트 소개

**마음, 한 잔**은 오프라인 솔로 파티의 선택 과정을 모바일 중심의 웹 경험으로 옮긴 프로젝트입니다. 참가자는 닉네임과 성별로 프로필을 만든 뒤 단계별로 마음을 전달하고, 마지막에는 자신에게 도착한 마음을 확인할 수 있습니다. 운영자는 별도의 관리자 화면에서 참가 현황과 단계별 제출률, 최종 상호 선택 결과를 확인할 수 있습니다.

단순 투표 화면에 그치지 않고 온보딩부터 선택, 확인, 대기, 결과 공개까지 행사 전체 흐름을 하나의 일관된 사용자 경험으로 설계했습니다.

## 핵심 기능

- **간단한 참가자 온보딩** — 닉네임과 성별을 등록하고 브라우저에 세션을 유지합니다.
- **3단계 선택 플로우** — 여성 1차, 남성 2차, 전원 최종 선택의 진행 규칙을 반영합니다.
- **두 가지 마음 표현** — 설레는 마음(빨강)과 더 알아가고 싶은 마음(노랑)을 구분합니다.
- **중복 제출 방지** — 완료한 단계의 선택은 다시 제출할 수 없도록 서버에서 검증합니다.
- **개인 결과 화면** — 참가자는 자신이 받은 마음만 단계별로 확인합니다.
- **운영자 대시보드** — 실제 참가자 수, 전달된 마음, 제출률, 최종 상호 선택을 집계합니다.
- **행사 시뮬레이션** — 8명이 모든 단계를 완료한 예시를 `/simulation`에서 살펴볼 수 있습니다.
- **반응형 인터페이스** — 모바일 중심의 카드형 UI와 따뜻한 색감으로 행사 분위기를 표현합니다.

## 사용자 흐름

```text
프로필 생성 → 성별에 맞는 선택 단계 → 선택 확인 및 제출
           → 다음 단계 대기 → 최종 선택 → 받은 마음 확인
```

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| Frontend | React 19, TypeScript, CSS |
| Full-stack framework | vinext, Vite |
| Runtime / Hosting | Cloudflare Workers |
| Database | Cloudflare D1 (SQLite) |
| ORM / Migration | Drizzle ORM, Drizzle Kit |
| Authentication | Sign in with ChatGPT 기반 관리자 인증 |
| Quality | ESLint, Node.js Test Runner |

## 주요 화면

| 경로 | 설명 |
| --- | --- |
| `/` | 참가자 온보딩, 단계별 선택, 결과 확인 |
| `/simulation` | 8인 행사 전체 흐름 데모 |
| `/admin` | 참가 현황 및 결과를 확인하는 관리자 대시보드 |
| `/api/app` | 프로필 생성, 상태 조회, 선택 제출 API |

## 데이터 모델

- `participants`: 참가자 프로필, 세션 토큰, 성별, 샘플 여부를 관리합니다.
- `choices`: 발신자·수신자·선택 단계·하트 색상을 저장합니다.
- 참가자/단계/하트 색상 조합에 유니크 인덱스를 적용해 같은 단계의 중복 선택을 방지합니다.

## 로컬 실행

### 요구 사항

- Node.js `22.13.0` 이상
- npm 또는 pnpm

### 설치 및 실행

```bash
npm install
npm run dev
```

개발 서버가 시작되면 안내된 로컬 주소에서 애플리케이션을 확인할 수 있습니다.

관리자 화면을 사용하려면 로컬 환경 파일에 관리자 이메일을 설정하세요.

```bash
# .dev.vars
ADMIN_EMAIL=you@example.com
```

`.dev.vars`는 저장소에 포함되지 않습니다.

## 명령어

```bash
npm run dev          # 개발 서버 실행
npm run build        # 프로덕션 빌드
npm test             # 빌드 및 렌더링 테스트
npm run lint         # 정적 분석
npm run db:generate  # Drizzle 마이그레이션 생성
```

## 프로젝트 구조

```text
app/
├── api/app/route.ts       # 참가자 상태 및 선택 API
├── admin/                 # 관리자 대시보드
├── simulation/            # 8인 행사 시뮬레이션
├── chatgpt-auth.ts        # 관리자 인증 헬퍼
└── page.tsx               # 참가자 메인 플로우
db/                        # D1 연결 및 Drizzle 스키마
drizzle/                   # 데이터베이스 마이그레이션
public/                    # 파비콘 및 OG 이미지
tests/                     # 렌더링 테스트
worker/                    # Cloudflare Worker 진입점
```

## 설계 포인트

- 참가자의 선택 내용과 결과 공개 범위를 분리해 개인정보 노출을 최소화했습니다.
- 실제 참가자와 샘플 참가자를 구분해 데모 경험과 운영 데이터를 함께 지원합니다.
- 관리자 이메일을 서버 환경 변수로 관리하고, 인증된 사용자만 운영 화면에 접근하도록 구성했습니다.
- D1 스키마를 런타임에 안전하게 보장하면서 별도 마이그레이션 파일도 함께 유지합니다.
